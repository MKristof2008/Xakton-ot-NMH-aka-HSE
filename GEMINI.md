# Инструкции проекта «Ревизор»

Фактчекинг сообщений: бесплатно вердикт, по подписке разбор.

## Раскладка
- `ml/doreposta/` — LLM-пайплайн фактчекинга: `extract_claims`, `evaluate_claims`,
  `validate_result`, `compose_reply`. Детерминированный валидатор цитат.
- `ml/lakmus/` — модель доверия: сигналы, fusion (субъективная логика), тарифы,
  база фактов `ml/lakmus/data/kb_facts.json`, эталонный набор `ml/data/eval_set.json`.
- `backend/` — FastAPI, SQLite (`store.py`: checks, feedback, лента).
- `frontend/` — React + Vite.
- `autopilot/` — автономный цикл «сбор → проверка → дообучение» (см. `autopilot/README.md`).

## Команды
```powershell
py -3 -m pytest -q                     # все тесты (ml + autopilot)
py -3 -m pytest autopilot/tests -q     # только автопилот
py -3 autopilot/smoke_live.py          # сквозная проверка на живых данных
py -3 -m autopilot run --once          # один цикл
.\autopilot\RUN_AUTOPILOT.ps1          # цикл 24/7
.\autopilot\STATUS.ps1                 # сводка: посты, метки, модель, источники
```

## Правила
- Ключ модели — `ml/.env` (`LLM_API_KEY`, `LLM_BASE_URL`, `LLM_MODEL`), в git
  не коммитится. Без ключа всё работает детерминированно (офлайн).
- Метка фейка в автопилоте ставится только при внешнем основании:
  опровержение фактчекеров, проверка утверждений пайплайном или цитаты
  LLM-арбитра, проверенные кодом. Собственный прогноз классификатора меткой
  не является.
- Обучающие данные берутся из проекта (`autopilot/training_data.py`):
  обратная связь бэкенда, `eval_set.json`, `kb_facts.json`, собранный корпус.
  Кейсы «непонятно» и факты `mixed` в обучение не идут.
- Очередь не крутится бесконечно: 3 попытки и TTL 48 ч, затем
  `archived_uncertain`. Пороги — в `autopilot/config.json`.
- Новая версия модели активируется по росту F1, либо по LogLoss/ROC-AUC/объёму
  данных при равном F1; первая активация — по абсолютному порогу.
- Не выдумывать цитаты и цифры: `validate_result` отбрасывает всё, чего нет
  в источнике. Меняешь правило — правь тест рядом.
- В конце каждого ответа писать, сколько минут заняла работа.
- `CLAUDE.md`/`GEMINI.md` создавать только в папке проекта, никогда в home.
