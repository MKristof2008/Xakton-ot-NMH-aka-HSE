## 1. Что это за продукт

**«Ревизор»** — фактчекинг для потребителя.

Пользователь вставляет сообщение из чата или пересылки, получает вердикт:
**правда / фейк / непонятно**. Бесплатно — только вердикт. По подписке —
разбор: почему такой вердикт, цитата из первоисточника, что проверить дальше.

Отличие от конкурентов (Лапша Медиа, SHOT Проверка, Проверено.Медиа):
**скорость и персональный инструмент**. У них разбор пишется редактором часами.
У нас — 3–15 секунд автоматически, и каждый ответ несёт постоянную ссылку
(«паспорт утверждения»), которую можно переслать.

Позиционирование: **мы не продаём проверку, мы продаём доступ к
проверенным свидетельствам и скорость.**

## 4. Как работает проверка

```
текст сообщения
      │
      ▼
[1] Проверка по базе фактов          ← 1 мс, без сети
      │   тема найдена и факт сверен → готовый вердикт
      ▼
[2] Поиск источников                  ← Serper, 3–10 сек
      │   база + интернет + ссылка пользователя
      ▼
[3] Оценка моделью                    ← 2–15 сек
      │   supported / contradicted / insufficient
      ▼
[4] Валидация цитаты                  ← детерминированный код
      │   цитата дословно в источнике? нет → вердикт понижается
      ▼
вердикт + разбор
```

**Главное правило:** модель не является источником истины. Она получает
тексты источников и обязана опираться только на них. Всё, что она вернула,
перепроверяется кодом.

**Репутация источников** (`ml/lakmus/reputation.py`): домены делятся на
`trusted` (госсайты, агентства, качественные СМИ), `satire` (Панорама и
подобные), `untrusted` (фабрики выдумок, подделки под известные адреса) и
`unknown`. Сатирический и недостоверный сайт **не может быть доказательством**:
его содержимое не идёт в опору модели. Подделка вида `cbr.ru.evil.com` не
наследует доверие `cbr.ru`.

**Строгий режим** (`STRICT_NOT_FOUND=1`, включён по умолчанию): если поиск был,
но подтверждений нет — вердикт «фейк» с баллом 25 и честным объяснением
«недостаточно подтверждений». Не применяется к прогнозам и безымянным
утверждениям — там «непонятно» единственно верный ответ.

**Четыре защиты от вранья модели:**
1. Подтверждение требует дословной цитаты из источника.
2. Прогноз о будущем не может быть ложью.
3. Безымянные утверждения («компания X») — непроверяемы.
4. Составные утверждения («запретил, но отменил») не опровергаются наспех.

## 5. Модели и ключи

### Модель

**`mimo-v2.6-flash`** через `https://api.smartapi.pro` — [OI]-совместимый шлюз.

Выбрана по замеру: качество 4/4 на тестовых кейсах, **177 токенов** в ответе,
дешевле остальных протестированных (deepseek-flash — 186, glm-flash — 248,
kimi-pro — 313).

### Важно: шлюз не передаёт system-промпт

Проверено напрямую: инструкция в `system` игнорируется моделью полностью.
Поэтому в `llm_pipeline.py` инструкция **склеивается с запросом** в одно
`user`-сообщение. Не «исправляйте» это обратно — сломается.

### Ключи (в `.env`, в git не попадают)

```
LLM_API_KEY=...        # обязателен для умной проверки
LLM_BASE_URL=https://api.smartapi.pro
LLM_MODEL=mimo-v2.6-flash
SERPER_API_KEY=...     # обязателен для поиска в интернете
```

Без ключей система работает только по базе фактов — и это даёт те же 26/28, что и с ключами.

## 6. Как проверить, что всё живое

```bash
# 1. Тесты — должны быть зелёные
python -m pytest -q                      # ожидаем 471 passed, 1 skipped

# 2. Качество на эталонном наборе
python -I ml/tools/eval_run.py                # без сети, ~1 мс на кейс
python -I ml/tools/eval_run.py --with-llm     # с ключами, 3–15 сек на кейс

# 3. Поднять локально
python -m uvicorn backend.main:app --port 8000
# открыть http://localhost:8000
```

Ожидаемые цифры: **26/28 (93%) без ключей**, **26–27/28 с ключами**.

Если сильно меньше — смотрите `ml/data/eval_report.json`, там провалы
по классам с пояснениями.

## 8. Правила работы

1. **Один файл — один хозяин.** Не править чужие зоны без договорённости.
2. **Тесты перед коммитом.** `python -m pytest -q` должен быть зелёным.
3. **Не коммитить `.env`.** В нём ключи. В git попадает только `.env.example`.
4. **Не врать в интерфейсе.** Если функция не работает — она помечена как
   неработающая. Никаких заглушек, выдающих себя за результат.
5. **Меняете промпт — прогоняйте `eval_run.py`** до и после. Иначе не увидите,
   что сломали.
6. **Ветки:** работа в `feat/<зона>`, мерж в `main` после зелёных тестов.
