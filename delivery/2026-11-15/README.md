## Как показать сайт

```bash
# 1. сервер
cd <корень репозитория>
py -3 -m uvicorn backend.main:app --port 8000

# 2. интерфейс (второй терминал)
cd frontend
npm install
npm run dev
```

Открыть http://localhost:5173 — рабочий интерфейс с живым API.

Второй вариант: собрать фронт один раз (`npm run build`), после этого
FastAPI сам отдаёт интерфейс на http://localhost:8000.

## Что проверить за три минуты

1. **Текст.** `СРОЧНО! ЦБ запретил снятие наличных с 1 марта 2026 года. Перешлите всем!`
   → «Скорее фейк», 15 / 100.
2. **Ссылка.** `https://www.cbr.ru/press/pr/` и текст про ставку 21% →
   «Скорее правда», 95 / 100, цитата из базы.
3. **Скриншот.** Вкладка «Скриншот», любой PNG/JPEG → семь сигналов:
   метаданные, следы генерации, монтаж, поиск первоисточника.
4. **Видео.** Вкладка «Видео», MP4 → метаданные контейнера, следы генератора.
5. **Паспорт.** «Скопировать ссылку» → страница `/p/<hash>` открывается без входа.

## Чего не обещать

- Оплата — симулятор, деньги не списываются (в интерфейсе написано).
- Без `SERPER_API_KEY` работает только база фактов (21 тема), без `LLM_API_KEY`
  нет извлечения утверждений из свободного текста.
- OCR текста со скриншота — только при установленном `pytesseract`.
- Звук и речь в видео не анализируются.
