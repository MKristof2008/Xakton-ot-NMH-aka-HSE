# Реферат и материалы к нему

Реферат по дисциплине «Информатика» на тему «Поиск и критическая оценка
информации в Интернете». Практическая часть — программа «Ревизор» из этого
же репозитория.

## Что где лежит

| Путь | Что это |
|---|---|
| `docs/referat/Реферат.docx` | готовый документ: 41 страница, оглавление, 13 таблиц, 9 рисунков |
| `docs/referat/Реферат.pdf` | тот же документ в PDF (для чтения и проверки вёрстки) |
| `referat/build_referat.py` | сборка документа: текст, таблицы, рисунки |
| `referat/make_figures.py` | схемы 1–7: цикл поиска, SIFT, конвейер, сигналы, шкала уровней, тарифы, метрики |
| `referat/make_shots.py` | кадры интерфейса 8–9: карточка вердикта и статистика автопилота |
| `referat/fig/*.png` | сами рисунки (300 dpi, годятся для печати) |

## Как пересобрать

Числа в документе не переписаны «на глаз»: сборщик сам прогоняет тесты,
читает отчёт о качестве и метрики модели, а пороги уровней доверия берёт
из кода.

```powershell
# 1. схемы из кода (пороги и метрики читаются из репозитория)
py -3 referat/make_figures.py

# 2. кадры интерфейса — нужен работающий сервер
py -3 -m uvicorn backend.main:app --port 8010
py -3 referat/make_shots.py

# 3. сборка документа; Word обновит оглавление и сохранит PDF
py -3 referat/build_referat.py
```

Для сборки нужны `python-docx`, `matplotlib`, `pillow`, `playwright` и
`pywin32` (последний — чтобы Word обновил оглавление и сделал PDF).
Без Word документ соберётся, но оглавление останется пустым: его надо
обновить в Word вручную (правка → обновить таблицу).

## Что в документе проверено кодом

- 471 тест проходит, 1 пропущен — число подставляется из прогона.
- Эталонный набор: 26 из 28 верных ответов (93 %) без ключей модели и поиска.
- Локальная модель автономного контура: F1 0,88 на отложенной выборке.
- База фактов: 21 тема, по одному факту в каждой.
- Пороги уровней доверия (35 / 60 / 80, «Туман» при неопределённости > 0,40)
  читаются из `ml/lakmus/fusion.py`, а не набираются руками.
